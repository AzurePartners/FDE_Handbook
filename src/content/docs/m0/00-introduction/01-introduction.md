**In one sentence:** Module 0 Is the map you read before anything else: what a Forward Deployed Engineer is accountable for, how the role differs from its neighbors, and which part of this handbook builds each capability the job needs.

## What Module 0 is for

Modules 1–8 cover software systems, AI applications, agents, production engineering, customer delivery, case studies, a practicum and interview preparation. To a reader who has never worked as or with an FDE, that is a long list of topics with no reason attached. Module 0 supplies the reason: every later module builds the capability for one or more stages of an FDE engagement.

There is no engineering in this module. It takes about 1.5 to 3 hours, and it is required for every background, including experienced engineers, because the rest of the handbook assumes its vocabulary.

## Two things to keep in mind

- **The title is not the job.** There is no industry standard for what "Forward Deployed Engineer" means. Companies use the same title for very different work, and other titles for the same work. This handbook defines the role by what it is accountable for, so you can place any job description you read.
- **Comparisons are about responsibility, not rank.** Lesson 2 compares the FDE with neighboring roles to make the boundaries clear, not to rank them. Most real FDE jobs cover only part of the full role, and that is normal.

## A note on sources

The four-responsibility model (Lesson 1) and the role tests (Lesson 2) are adapted from Xu Liang's *The FDE Handbook* (Chinese, 2026), Chapters 1–3, with one deliberate change: this handbook does not treat consulting as "advice without code." Large technology consulting firms design, build and run production systems; [FDE vs Consultant and Systems Integrator](../02-fde-vs-adjacent-roles/05-fde-vs-consultant-and-systems-integrator.md) explains what actually separates that work from an FDE's. All Learn more resources are in English.
