**一句话：** 定期的书面进度更新（每周的进展和清晰的风险提示）能让远程的利益相关方不开会也保持步调一致，而把它做好（简洁、坦诚、先讲风险和请求）是面向客户的工作中一项不张扬的超能力。

## 是什么

**进度更新**告诉利益相关方事情进行到哪一步了：完成了什么、接下来做什么、什么被卡住或有风险，以及需要他们做的决策或提供的权限。它按固定的**节奏**（常见的是每周一次）以**书面**形式发出，这样既能异步进行，也方便回头查阅。一份好的更新很短，**先讲要紧的事**（风险、阻碍和请求，而不是一本任务流水账），对问题**坦诚相告**，并让需要做的决策容易落实。**风险提示**，也就是尽早提出进度延误或担忧，是其中最有价值的部分。

## FDE 为什么需要

FDE 的工作常常是远程、跨时区的（本课程本身就在固定时段内通过微信提供助教支持），所以异步的书面沟通，就是在演示和会议之间保持各方步调一致的办法。一份干净利落的每周更新能及早暴露风险，留下记录，并传递出专业和掌控力。沟通不畅、沉默，或是把重点埋掉的冗长更新，即便工作本身没问题，也会削弱对方的信心。清晰的书面更新，才能换来独立工作所需的信任。

## 核心概念

- **节奏：** 固定且可预期（比如每周一次）。
- **先讲风险和请求：** 先写阻碍和需要的决策，而不是按时间顺序的流水账。
- **坦诚而具体：** 点明真实的风险和延误；含糊的“一切都好”会失去可信度。
- **可操作的请求：** 写明需要的决策 / 权限，以及负责人和截止日期。
- **书面且异步：** 可供查阅，照顾时区差异，减少会议。

```
每周更新：
- 已完成：……
- 下一步：……
- 风险 / 阻碍：……
- 需要你提供（决策 / 权限，截止时间）：……
```

## 常见误区

- **“工作在推进，没消息就是好消息。”** 沉默会被理解成出了问题，还会掩盖风险；无论如何都要按节奏更新。
- **“更新就是一份完整的活动日志。”** 把重点埋掉就失去了意义；先讲风险和请求。
- **“只汇报好消息。”** 坦诚的风险提示才让更新值得信赖，也让问题能被尽早处理。

## 典型面试题

<details>
<summary>什么样的书面进度更新才算好？</summary>

它定期发出、篇幅简短，并且先讲要紧的事：风险、阻碍，以及需要利益相关方做的决策或提供的权限，而不是按时间顺序罗列任务。它对问题保持坦诚，因此可信；请求都可操作，写明负责人和截止日期。采用书面、异步的形式，所以可供查阅，也适用于跨时区协作。

</details>

<details>
<summary>为什么要按节奏用书面形式沟通进度，而不是只靠开会？</summary>

因为异步的书面更新能让所有人保持步调一致，又没有开会的开销；它适用于跨时区，会留下持久的记录，并以可预期的节奏尽早暴露风险。两次会议之间的沉默会滋生焦虑、掩盖问题；一份可靠的每周更新则传递出一切在掌控之中的信号，并赢得独立工作的信任。

</details>
